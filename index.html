Ligar a nuvem

Isso é feito uma vez. Cria o “armário” na internet onde os dois celulares vão guardar a agenda.

  1. No computador, abra supabase.com e entre com o Google.
  2. Clique em New project. Nome: agenda-juridica. Região: South America (São Paulo).
  3. Quando o projeto abrir, vá em SQL Editor → New query, cole o SQL (botão abaixo) e clique em Run.
  4. Em Project Settings → API, copie o Project URL e a chave anon public.
  5. Cole os dois campos abaixo neste celular. No outro, cole os mesmos dados e depois entre com o código.
